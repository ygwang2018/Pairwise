# Pairwise Robust Estimation under Contamination and Dependence

This repository contains the code used to reproduce the simulation study in the paper:

The project investigates the finite-sample performance of a **pairwise robust estimator** under challenging data conditions, including **heteroskedasticity, serial dependence, and contamination**.

---

## 📌 Overview

The simulation study is designed to evaluate:

- Robustness to contamination (outliers)
- Stability under serial dependence (AR(1) errors)
- Adaptability to heteroskedasticity

We compare four estimators:

- Ordinary Least Squares (OLS)
- Robust M-estimator (non-pairwise)
- Pairwise Least Squares (pairwise LS)
- **Proposed Pairwise Robust Estimator**

Performance is assessed using:

- Root Mean Squared Error (RMSE)
- Bias
